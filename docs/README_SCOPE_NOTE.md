# Janus-Cosmos scope note

Janus-Cosmos is not limited to outer space. It is the JANUS domain for planetary-scale observation, reconstruction, calibration, and falsification across the whole physical environment: sky, near-Earth space, land, oceans, seas, seafloor, atmosphere, and coupled Earth-space systems.

The repository treats these domains as one connected measurement problem. A signal may begin in one layer and only become interpretable by comparing it with another: satellite geometry with ground truth, ocean acoustics with bathymetry, sonar with navigation and sound-speed models, atmospheric propagation with astronomical timing, or synthetic controls with real observations.

Core principle: **raw data outrank stories**. Janus-Cosmos keeps positive, negative, ambiguous, and blocked results; freezes coordinates and hypotheses before unblinding where possible; separates instrument artefacts from physical features; and requires independent replication before strong claims.

The Cousteau branch extends this architecture into oceans and seas. It includes multibeam, sidescan, bathymetry, hydroacoustics, navigation, sound-speed calibration, seafloor morphology, instrument-failure controls, and blind synthetic replay. Its current BODC/Hannah lane uses a bidirectional START↔EOF analysis and a TIME→SPACE convergence gate before any morphology claim.

In short:

**COSMOS = SPACE + EARTH + OCEAN + ATMOSPHERE + THEIR COUPLINGS.**

Not everything unusual is exotic; not every failure is noise; and not every apparent structure is real. JANUS exists to force those alternatives to meet the data.
