JANUS COSMOS v2.0.2 — PORTABLE DETECTOR IDENTITY FIX
====================================================

Observed failures
-----------------
v2.0 hashed raw synthetic validation floats and failed across numerical stacks.
v2.0.1 rounded those metrics to 12 decimal places, but still failed on:

  Python 3.14 / NumPy 2.5.2 / SciPy 1.18.0 / Windows

Root cause
----------
Detector identity and platform-specific numerical evidence were incorrectly
treated as one byte-identical object. A scientific receipt may preserve exact
floating-point evidence without requiring every numerical library build to emit
the same final bits.

v2.0.2 proof layers
-------------------
1. freeze_sha256 binds the portable detector identity:
   - selected genome and genome_sha256;
   - validation PASS decision;
   - normalized source and manifest hashes;
   - blind-wall declaration;
   - fixed numerical-conformance contract.

2. metrics_sha256 binds the exact raw metrics emitted by the current platform.

3. FORGE_METRIC_REFERENCE_v2_0.json is source-hash bound and admits only a
   2e-6 absolute/relative cross-platform deviation. The scientific gate itself
   still evaluates unrounded raw values.

4. self_test_v2_0.py proves that harmless metric drift does not alter detector
   identity, exact evidence drift does alter metrics_sha256, and material drift
   is rejected by the tolerance gate.
